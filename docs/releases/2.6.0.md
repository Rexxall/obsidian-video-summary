# Video Summary 2.6.0

Interface release. Includes the fixes from 2.5.0, which was not published separately.

- New look that follows your Obsidian theme and light/dark mode; optional **Paper & ink style**.
- One add box in the side panel, with 只要文稿 / 总结 / 证据 and a 学习卡 checkbox; other options folded.
- Failed jobs show a next step.
- Settings on one page: 连接 / 输出 / 处理, with 高级 folded.
- Browser extension 0.4.0: opens on the current video with one main button.
- From 2.5.0: processing follows your Timeout setting, cancel reaches the Worker, notes you edited
  during processing are never overwritten, renamed notes stay linked.

Assets: `video-summary-2.6.0.zip` (plugin), `video-summary-capture-0.4.0.zip` (browser extension),
`Obsidian.Video.Summary.json` (optional n8n workflow), `SHA256SUMS`.

Hotkeys assigned in a manually installed 2.4.1 build need to be set once more.
