# Video Summary 2.5.0

Reliability release, plus the browser extension.

- Processing follows your Timeout setting (default 30 minutes) instead of a hidden 10-minute limit.
- Cancelling a task also cancels it on the Worker.
- The plugin never overwrites a note you edited while it was processing.
- Notes stay clean by default: summary and folded transcript; diagnostics on request.
- Renamed notes stay linked to their tasks.
- New: **Video Summary Capture** browser extension (`video-summary-capture-0.3.0.zip`).

Assets: `video-summary-2.5.0.zip` (plugin), `video-summary-capture-0.3.0.zip` (browser extension),
`Obsidian.Video.Summary.json` (optional n8n workflow), `SHA256SUMS`.

Hotkeys assigned in a manually installed 2.4.1 build need to be set once more.
