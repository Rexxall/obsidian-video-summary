# Video Summary 2.12.0

- When a video fails, its details say where the transcript should have come from (the video's subtitles, and speech-to-text when it matters), what went wrong, and the one next step for that cause. Retry is hidden where it would fail the same way.
- Pasting a transcript finishes the same job: same title, same note, the link kept as the source, nothing downloaded or transcribed again.
- The install guide shows how to allow `start-mac.command` on current macOS (System Settings → Privacy & Security → Open Anyway).

**Update the backend:** unzip `video-summary-backend-2.12.0.zip` over the old backend folder (your `.env` stays), then run `./vs-backend.sh update` (Windows: `.\vs-backend.ps1 update`).
