# Video Summary 2.4.1

Video Summary 2.4.1 turns the redesigned media library into a local, evidence-aware video
knowledge workflow. It is the first public release to combine the 2.2–2.4 sidebar, reliability,
metadata, and knowledge-system work.

## Highlights

- Evidence map with timestamped transcript segments, source-labelled claims, provenance, stable
  artifact IDs, and user-safe managed Markdown updates.
- Synchronized reader for local media and YouTube, transcript seeking, persistent highlights, and
  accessible keyboard interaction. Bilibili is click-to-seek only.
- Honest `quick`, `evidence`, and `deep-visual` depth controls. The bundled n8n workflow supports
  evidence depth; deep visual requires a separately deployed compatible Worker, ffmpeg, and a
  configured visual model.
- Automatic or manual routing for courses, interviews, tutorials, news, meetings, reviews, and
  general videos.
- Transparent watch / skim / skip attention assessment with bounded source ranges.
- Incremental YouTube playlist and Bilibili collection course manifests that create pending notes
  without automatically calling a model.
- Review-gated multi-video Claim Lab and local cross-modal search over transcript, OCR, screen text,
  visual descriptions, metadata, and claims.
- Local learning review with flashcards, questions, attempts, confidence, mastery, and due dates.
- Offline-first URI capture, managed Obsidian Base views, and validated reprocessing from local
  evidence snapshots.
- Direct cover retrieval for YouTube and Bilibili links, plus metadata/status reconciliation.
  Other sources show a cover only when the configured backend returns one.

## Install or update

1. Download `video-summary-2.4.1.zip` below.
2. Extract `main.js`, `manifest.json`, and `styles.css` directly into:

   ```text
   <your-vault>/.obsidian/plugins/video-summary/
   ```

3. Restart Obsidian and enable or reload Video Summary.

`Obsidian Video Summary.json` is a separate, optional n8n workflow import. Do not place it in the
Obsidian plugin folder.

The manifest minimum is Obsidian 1.4.0; this release was exercised on desktop Obsidian 1.12.7 and
is declared desktop-only. Generated `.base` views require Obsidian 1.9.10 or newer with the Bases
core plugin enabled. Rich knowledge state is stored locally under the plugin's `data/` directory.
Back up that directory privately if you want artifacts, learning progress, and course state to
survive a clean reinstall.

## Backend boundaries

- The bundled n8n workflow can download supported sources, obtain native subtitles, and return
  speech-based evidence.
- Local files for bundled n8n must first be copied into `docker/uploads/`; requests use only a safe
  file name or relative path below that folder. Host absolute paths are not visible in the
  container.
- Audio fallback is an explicit integration point: the public export uses
  `CONFIGURE_ASR_WORKFLOW_ID` in two nodes. Supply your own ASR subworkflow for no-subtitle videos
  and local audio/video; the ASR workflow and provider credentials are not bundled.
- Its video-frame analysis path is not connected. The separate Gemini Vision node serves local
  image/PDF OCR; n8n does not claim that path inspected video frames.
- A compatible Codex Worker can provide progress, cancellation, and deep visual results only when
  separately deployed and configured. The Worker service is not bundled in this repository or
  release.
- Douyin, TikTok, and Xiaohongshu/Rednote remain cookie-sensitive best-effort sources.
- Bilibili reader playback does not expose reliable automatic time tracking in this release.

See the
[backend capability matrix](https://github.com/Rexxall/obsidian-video-summary-plugin/blob/2.4.1/docs/BACKEND_CAPABILITY_MATRIX.md)
for the full comparison.
