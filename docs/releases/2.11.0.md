# Video Summary 2.11.0

- Shorter notes in the language you asked for: a summary, key points with their times, and short sections for the kind of video. Before, the prompt reached the model as unevaluated code, so the language setting was not applied.
- The n8n workflow names every step for what it does, has one AI step instead of two, and carries sticky notes that explain each lane and where to look when something fails.
- The "Codex local video service" backend and "Deep visual" are removed; settings that used them switch to n8n.

**Update the backend:** unzip `video-summary-backend-2.11.0.zip` over the old backend folder (your `.env` stays), then run the start script.
