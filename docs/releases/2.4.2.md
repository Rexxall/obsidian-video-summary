# Video Summary 2.4.2

Video Summary 2.4.2 is a security and Obsidian community-directory readiness release. The plugin's
knowledge features are unchanged; the release tightens the bundled local backend and corrects
distribution metadata.

## Update promptly if you use the bundled n8n workflow

The workflow contract 2.1.4 bundled with plugin 2.4.1 accepted untrusted URL and local-file fields
in command and path expressions. Contract 2.1.5 bundled with plugin 2.4.2 validates and canonicalizes
supported platform URLs before media tools run, accepts only safe basenames from the mounted uploads
root, and no longer disables TLS certificate checks. The Docker port is now published only on
`127.0.0.1`; n8n is pinned to 2.35.7 and yt-dlp to 2026.8.19.

Do not expose the bundled n8n container directly to a LAN or the public internet. Remote deployments
need TLS, authentication, rate limiting, current security updates, and their own security review.

To update the backend:

1. Disable the existing Video Summary workflow in n8n.
2. Back up any instance-specific prompts, model credentials, and ASR subworkflow selection.
3. Import the new `Obsidian.Video.Summary.json` asset and restore only those reviewed settings.
4. Create/select an n8n Header Auth credential on `Webhook`, then enter its matching header name and
   secret in the active Obsidian profile. Model keys remain in n8n Credentials; `Gemini Vision`
   uses `x-goog-api-key`, never a URL query parameter.
5. Rebuild the supplied Docker image without cache so it installs the pinned versions.
6. Confirm the container publishes `127.0.0.1:5678`, activate the new workflow, and run the setup
   check with a non-sensitive transcript before processing real material.

## Obsidian directory fixes

- Internal command IDs no longer repeat the `video-summary` plugin ID.
- `versions.json` now references only real published releases plus this candidate.
- The README explicitly discloses network requests, remote covers, optional account/API costs, and
  access to a configured cookies directory outside the vault.
- Model-authored Markdown cannot auto-load image, iframe, SVG, media, or embed resources during
  preview or managed-note insertion; inline covers use an explicit platform-media allowlist, and
  Worker keyframes must be localized after hash/root validation.
- Worker asset localization runs only for the active Worker backend, requires its exact configured
  loopback origin and fixed asset path, and disables redirects. Reader refuses URL schemes and
  absolute paths in `local_file`, auto-loading only an existing Vault file. Fresh backend payloads
  cannot claim an already-localized Vault path; trusted paths are tied to the plugin-recorded media
  root.
- Pull requests and main-branch changes now run tests, lint, formatting, workflow validation, a
  production build, and committed-bundle drift detection.

### Hotkey migration

The command labels and behavior are unchanged, but their internal IDs changed to meet Obsidian's
submission requirements. If you assigned custom Video Summary hotkeys in a manually installed
2.4.1 build, assign them once more in Obsidian's Hotkeys settings after updating.

## Install or update

After the release is published, download `video-summary-2.4.2.zip`, verify it against
`SHA256SUMS`, and extract exactly `main.js`, `manifest.json`, and `styles.css` into:

```text
<your-vault>/.obsidian/plugins/video-summary/
```

Restart Obsidian, then enable or reload Video Summary. The separately attached
`Obsidian.Video.Summary.json` is an n8n import and must not be copied into the plugin folder.

## Verification

The release candidate must pass the full plugin test suite, ESLint, Prettier, workflow structural
checks, a reproducible production build, and a clean local n8n smoke test before the tag is pushed.
The GitHub release workflow rechecks versions, bundle drift, ZIP contents, and checksums.

## Release assets

- `main.js`, `manifest.json`, `styles.css` — required Obsidian plugin assets.
- `video-summary-2.4.2.zip` — convenience archive containing exactly the three runtime files.
- `Obsidian.Video.Summary.json` — optional hardened n8n workflow import.
- `SHA256SUMS` — checksums for the downloadable assets.
