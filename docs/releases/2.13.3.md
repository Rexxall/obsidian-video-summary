# Video Summary 2.13.3

- **Finished video notes open in reading view.** Their photos, stamps and callouts read as code in the editor. A finished note now asks for reading view when it opens, and gets `obsidianUIMode: preview`, the property view plugins such as View Mode by Frontmatter read, so a vault that forces other notes back to editing still shows it as written. A value you set yourself is kept. Turn it off under **Settings → Video Summary → Open video notes in reading view**.
- **History finds notes that were renamed or moved.** A record now keeps the note's path and follows it through renames. Older records, which kept only the name at the time, are matched by the video's title, the copy name without "(1)", and the link. A record whose note is gone says so instead of _Note not found_, and **Remove records whose note is gone** in the list menu clears them; notes are not touched.
- **Opening notes stays fast.** Typing in any note no longer redraws the library on each pause, switching notes redraws only the current-note card, the hidden top bar is no longer rebuilt on every switch (each rebuild also left a listener behind, so Obsidian slowed down the longer it ran), and the library draws 30 rows at a time, the next ones as you scroll.
